# Crown Gambit 简体中文汉化

适用于 Steam Windows 版《Crown Gambit》1.0.6。

本汉化覆盖全部章节、分支、结局、旅行事件、战斗对白与日志，并统一了人名、地名、阵营、神祇和世界观术语。卡牌、状态、教程、百科、按钮文本及部分界面布局也已进行精修。

## 安装方法

1. 关闭游戏。
2. 下载并解压对应压缩包。
3. 将解压出的汉化包文件夹放入 `Crown Gambit` 游戏目录。该目录中应能看到 `crown_gambit_windows.exe`。
4. 双击完整版中的“安装汉化.bat”，或更新包中的“安装文本更新.bat”。
5. 等待校验和安装完成，然后从 Steam 启动游戏。

安装器会验证游戏文件版本并自动创建备份。完整版可通过“还原原版.bat”恢复；文本更新包的还原脚本只会恢复到更新前的旧版汉化。

完整版安装期间需要约 8 GB 可用空间；从较早版本执行桥接更新时最多需要约 16 GB。Steam 更新或“验证游戏文件完整性”可能覆盖汉化，届时重新安装完整版即可。
