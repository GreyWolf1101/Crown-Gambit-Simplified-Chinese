# 《Crown Gambit》敌人特殊状态与能力图鉴

> **防剧透说明：** 本页只按“第几章”分组，不写章节标题、剧情身份、阵营转折、出场地点、战斗结果或结局信息。每章敌人表默认折叠；只有主动展开对应章节，才会看到该章敌人与 Boss 名称。
>
> 数据依据游戏 1.0.6 的实际战斗配置、角色场景、技能与被动资源生成。不同剧情分支可能只会遇到表中的一部分敌人；终局章节会因路线差异出现较多变体。

## 阅读说明

- “Boss”仅表示游戏资源中的首领标记，不说明其剧情身份。
- 同名敌人的多个数值或阶段变体已合并；能力只列一次。
- “一定数值”表示该数值由具体战斗、阶段或难度资源决定。
- 状态名称与 v1.2.6 汉化保持一致。

<summary><strong>常见状态速查</strong>（点击展开）</summary>

| 状态 | 核心效果 |
| --- | --- |
| **蓄势** | 每层使下一次攻击获得额外伤害。 |
| **好斗** | 提高造成的所有伤害。 |
| **出血** | 回合结束时受到基于层数的伤害。 |
| **目盲** | 降低造成的伤害。 |
| **血之屏障** | 免疫来自屏障朝向一侧的所有伤害。 |
| **灼烧** | 下一回合结束时，按最大生命值百分比损失生命值。 |
| **腐蚀** | 回合开始时损失护甲。 |
| **反击** | 受到攻击后对攻击者造成伤害。 |
| **铤而走险** | 生命值降至 0 以下时以一定比例生命值重返战场。 |
| **闪避** | 若存在可移动空格，则移动并使下一次以自身为目标的攻击失效。 |
| **汲取** | 每层从目标吸取 1 点生命值并为施术者恢复等量生命值。 |
| **醉酒** | 下一次受到攻击时，对自身施加动摇。 |
| **鼓励** | 力量暂时 +1。 |
| **信仰** | 为部分特殊攻击提供额外效果或伤害。 |
| **胆怯** | 限制单次攻击最多能够造成的伤害。 |
| **狂乱** | 自身回合开始时获得活力。 |
| **恐惧** | 降低下一次攻击造成的伤害。 |
| **冰冻** | 回合结束时，每层使角色损失生命值。 |
| **悲伤** | 与希朗斯的鸟类机制联动。 |
| **头铁** | 下一轮开始时获得活力。 |
| **定身** | 直到下回合前无法移动。 |
| **污秽** | 层数越高，敌方 AI 越会优先攻击该目标。 |
| **隐身** | 敌人无法将该角色视为目标。 |
| **戒备** | 降低下一次命中该角色的攻击伤害。 |
| **中毒** | 下一回合结束时，按最大生命值百分比损失生命值。 |
| **威力** | 提高下一次攻击造成的伤害。 |
| **护主群鸟** | 附近鸟类会替希朗斯承受下一次以她为目标的攻击伤害。 |
| **动摇** | 下回合减少 1 次行动。 |
| **迅捷** | 下一次移动不消耗行动点。 |
| **坚不可摧** | 限制单次攻击最多能够损失的生命值。 |
| **活力** | 下一轮额外获得 1 次行动。 |
| **易伤** | 提高下一次命中该角色的攻击伤害。 |
| **虚弱** | 力量降低 1 点。 |
| **专注** | 抵消动摇。 |
| **不死** | 直到下回合开始前，生命值最低保留 1 点。 |
| **再生** | 下回合开始时按最大生命值百分比恢复生命值。 |
| **烈焰武器** | 下一次攻击额外施加灼烧。 |
| **祝福** | 下一次使用先祖技能时不增加先祖影响。 |
